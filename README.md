# Cognition GTM Plan

Day 1 framework for building Cognition's Industrial & Energy vertical: the ICP, target accounts, personas, a 90-day plan, and first plays, with notes from *Make It Snow*.

The site is a single `index.html`. Each chapter is a `<section class="chapter">`; new book notes go in chapter 03 as additional `<article class="note">` blocks.

To publish: Settings → Pages → Deploy from branch → `main` / root.
